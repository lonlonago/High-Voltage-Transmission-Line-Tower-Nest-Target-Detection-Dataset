# High Voltage Transmission Line Tower Nest - Target Detection Dataset

Dataset Information Introduction: The dataset consists of 1583 images and corresponding labeled files.
The labeled files are provided in two formats: VOC-formatted xml files and YOLO-formatted txt files.
The target objects include the following:
['nest']
The number of bounding box annotations is as follows: (Annotations are generally labeled in English, with Chinese provided for reference inside brackets)
'nest': 1605
Note: One image may contain multiple annotated objects, so the total number of bounding boxes might be greater than the number of images.
The complete dataset includes three folders and one txt file:
all_images file: Stores the dataset images, screenshots included:
Image size information:
all_txt folder and classes.txt: Stores the YOLO-formatted txt annotations, in the same quantity as the images, each annotation file corresponds to an image.
classes.txt:
For a detailed understanding of the YOLO-format standard file, please search for it yourself on Baidu. In short, index 0 represents the name of the object at array index 0 in classes.txt.
all_xml file: VOC-formatted xml annotation files.
Number and quantity match those of the images, each annotation file corresponds to an image.
For a detailed understanding of the VOC-format standard file, please search for it yourself on Baidu.
Both formats of annotations can be used, choose one of them accordingly.
